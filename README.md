# Where the Fallen Kneel

A dark boss-rush game that runs in your browser. You are a knight taken from a burning village and thrown into trials where you fight one boss after another. Win coins, buy weapons and abilities, and clear every trial.

**Early version.** More is planned, and some things are still being tuned.

## Play

Open `index.html` in a browser, or play online at: _add your GitHub Pages link here_

There is nothing to install and no build step. Saves are kept in your browser, so they stay on the device and browser you play on.

## Controls (keyboard)

| Action | Key |
| --- | --- |
| Move | Arrow keys |
| Jump | D (press again in the air once you own Wraith Wings) |
| Attack | S |
| Aim | Hold Up or Down |
| Heal | Hold A |
| Dash | F |
| Bee Bolt | W |
| Interact | Up |
| Pause | Esc |

## What is in it

- The village raid, a hub with a smith and a peddler, and three trials: the Pits, the Trial of the Bugs and the Foundry.
- Bosses with several attacks each, some with more than one phase.
- Weapons and abilities to buy, three save files, achievements, and a completion percent for each file.
- All art and music are drawn and played by the code, so the whole game is under 1 MB.

## Settings

The Settings screen has a volume control and a Dev tools switch (off by default). When it is on, 8 and 9 turn invincibility on and off and 0 shows hitboxes.
